# Advanced Machine Learning Vision Project

**Graduate Course Project — ECE 8487: Advanced Machine Learning**  
**Institution:** Villanova University  

This repository contains the source code and analysis for a graduate-level machine learning project completed as part of the course *ECE 8487: Advanced Machine Learning*. The project was conducted as a **collaborative group project** and focuses on applying modern deep learning techniques to a computer vision task, including both model development and application-level integration.

---

## Project Overview

The objective of this project was to design, evaluate, and compare multiple deep learning architectures for a real-world computer vision problem, and to integrate trained models into an application framework suitable for real-time or interactive use. The project emphasizes not only model performance, but also evaluation, interpretability, and deployment considerations.

The work includes:
- Custom deep learning model development
- Evaluation using classification metrics and confusion matrices
- Comparative analysis across architectures
- Integration of trained models into an application pipeline

---

## Models and Methods

The project explores and evaluates multiple deep learning approaches, including:

- Custom Convolutional Neural Networks (CNNs)
- Vision Transformer–based models
- Comparative performance analysis using standard ML metrics

The modeling and evaluation workflow was implemented using Python and common deep learning libraries, with analysis performed through Jupyter notebooks.
